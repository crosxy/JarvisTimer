## 📌 Sobre o Projeto

O **Jarvis Timer** é um assistente desktop desenvolvido para auxiliar no controle de tempo de objetivos, respawns e rotinas dentro de partidas. 

Desenvolvido em **Python** utilizando **PySide6**, o projeto conta com uma interface moderna, leve e com suporte a **atualizações automáticas via GitHub**.

---

## ✨ Funcionalidades

- ⏱️ **Timer de Objetivos:** Acompanhamento dinâmico e em tempo real.
- 🎨 **Interface Intuitiva:** Feita com PySide6 para ser leve e visualmente agradável.
- 🔄 **Auto-Update Integrado:** O aplicativo verifica se há novas atualizações publicadas no GitHub e atualiza sozinho ao iniciar.
- 📦 **Instalador Windows:** Executável pronto para instalação no Windows com atalhos na Área de Trabalho e Menu Iniciar.

---

## 🚀 Como Baixar e Usar

1. Acesse a aba de **[Releases](https://github.com/crosxy/JarvisTimer/releases/latest)**.
2. Baixe o executável mais recente (`JarvisTimer_Setup_v1.0.0.exe` ou `main.exe`).
3. Execute o instalador e abra o aplicativo!

## 💻 Para Desenvolvedores (Rodando o Código)

Se você deseja clonar o repositório e executar localmente:

### Pré-requisitos
- Python 3.11+
- Pip instalado

### Passo a passo
```bash
# 1. Clone o repositório
git clone [https://github.com/crosxy/JarvisTimer.git](https://github.com/crosxy/JarvisTimer.git)

# 2. Entre na pasta do projeto
cd JarvisTimer

# 3. Instale as dependências
pip install -r requirements.txt

# 4. Execute o projeto
python main.py
